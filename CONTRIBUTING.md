# Contribution Policy

GRAPH1KS Prompt Control Deck is a public, owner-controlled solo-development project.

## Code contributions

Unsolicited external code contributions are not accepted.

Please do not open pull requests for code, refactors, documentation changes, dependency changes, or factory-data changes unless Graph1ks explicitly invited that specific contribution.

Public visibility and forking do not imply an open contribution workflow or community governance.

If the project later enables external code contributions, the contributor-rights, licensing, review, and repository-settings model will be decided explicitly before contributions are accepted. No CLA/DCO process is currently active.

## Bug reports and suggestions

Issues may be used for:

- reproducible bugs;
- compatibility problems;
- feature suggestions;
- user feedback.

An Issue is input, not a roadmap commitment or guarantee of implementation or response.

Do not post credentials, private prompts/lyrics, Vault exports, tokens, browser/session data, or exploitable security details in a public Issue.

For vulnerabilities, follow SECURITY.md.

## Owner development workflow

Graph1ks and explicitly authorized collaborators should:

- use one branch per coherent task when isolation is useful;
- avoid branch-per-file or branch-per-minor-tweak churn;
- keep changes focused;
- preserve user data/migrations unless intentionally changed;
- avoid silent changes to licensing, permissions, telemetry/network behavior, factory data, or versioning;
- prefer browser-native capabilities over unnecessary dependencies;
- run relevant local validation before relying on CI.

See AGENTS.md, PROJECT.md, and docs/DEVELOPMENT.md for the authoritative development contract.
