GRAPH1KS PATCH / UPDATE JSON

A patch changes one declared field only. It never replaces whole track records.

{
  "schema": "graph1ks-db-patch-v1",
  "field": "instrumental_arrangement",
  "match_by": "id",
  "updates": [
    { "id": 1851, "value": "[Intro]\n..." },
    { "id": 1852, "value": "[Verse]\n..." }
  ]
}

Single-song patch: use one update object. All arrangements: include one update for every song you want changed.

Private Vault matching: set "match_by": "suno_song_id" and use "suno_song_id" in each update.

Protected provenance: Private Vault patches cannot modify Artist identity/profile fields, Suno Song ID/link, source URL, record type/retrieval identity, Reference Artist or Reference Song. Those fields are refreshed only from authoritative Suno retrieval/identity updates.

Accepted field aliases: arrangement/lyrics → instrumental_arrangement, styles → structured_prompt, exclude → negative_prompt.

You may use updates[], records[], or tracks[]. The value may be stored as value or under the declared field name, for example {"id":1851,"instrumental_arrangement":"..."}. Extra fields are ignored.
